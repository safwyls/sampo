Artificer design systems

Reliquary

the vault of shared worlds

One deliberate dark look — no light theme and no toggle, so there is exactly one palette. Reliquary is game-blind custody: it holds other people's worlds and hands them back, and the interface is built so a player can answer "can I take this?" from across the room. That is what the custody chip, the one-primary-action rule and the badge vocabulary are all for.

Foundations

  • Palette 11 tokens, one theme
  • Type Georgia throughout, mono for machine facts
  • Surfaces Panel, well, dashed well, 8px corner
  • Focus One gold ring, offset from the page ground

Actions

  • Buttons Primary / quiet / danger, four sizes
  • Overflow menu The rare and admin verbs, one click away

Forms

  • Fields Label above, input on ink
  • Confirm dialog What the action costs, not that it is irreversible

Status

  • Custody chip Free / Held / Hold expired
  • Version badges HEAD / CONFLICT / CHECKPOINT
  • Toasts and the live dot Every action says what happened, or why it didn't

Patterns

  • Cover art The image, and the tile for when there isn't one
  • World card Cover, custody, and the single action custody calls for
  • Version row One kept version, badges first
  • App shell Sidebar, page header, footer identity
  • Login Password box, and three distinguishable SSO hints
